KURONOMY CLIENT SETUP

MODインストーラー

KURONOMYに参加するためのMOD、Fabric環境、サーバーリスト登録をまとめてセットアップするWindows向けツールです。

今すぐダウンロード トップへ戻る Discord

WINDOWS AUTO SETUP

KURONOMY-Mod-Installer.exe

Minecraftのフォルダを探して、必要なMOD一式を配置し、Fabricの起動環境を構築し、マルチプレイのサーバーリストにKURONOMYを登録します。手動でMODを集めたり、modsフォルダを探したりする手間を減らすための専用インストーラーです。

TARGET Minecraft Java 1.20.1 Fabric
SERVER xero-x.me
SIZE 約305 MB

ダウンロード

下のボタンから最新版のインストーラーをダウンロードできます。保存したEXEを実行すると、KURONOMY向けのクライアント環境を自動で準備します。

KURONOMY-Mod-Installer.exe をダウンロード

SHA-256: 3FEE5871EB44FAECC99DE82430A3D3A0316A44214186BE8814694E910FA69AAB

このソフトが自動で行うこと

  • KURONOMYで必要なMOD一式をMinecraftのmodsフォルダへ配置します。
  • Fabric Loaderと1.20.1向けの起動環境を作り、ランチャーから選べる状態にします。
  • マルチプレイのサーバーリストへ xero-x.me を登録します。
  • 手動導入で起きやすいバージョン違い、入れ忘れ、保存先ミスを減らします。

使い方

  1. Minecraft LauncherとMinecraft本体を閉じます。
  2. インストーラーをダウンロードして実行します。
  3. 案内に沿ってセットアップを進めます。
  4. 完了後、Minecraft LauncherでFabric 1.20.1の起動構成を選びます。
  5. マルチプレイ画面からKURONOMYを選んで接続します。

うまくいかないとき

  • Windowsの警告が出た場合は、配布元とファイル名を確認してから実行してください。
  • 既存のMOD構成を残したい場合は、先にmodsフォルダをバックアップしておくと戻しやすくなります。
  • ランチャーにFabricが出ない場合は、Minecraft Launcherを完全に閉じてからもう一度開いてください。
  • 接続できない場合は、サーバーアドレスが xero-x.me になっているか確認してください。
